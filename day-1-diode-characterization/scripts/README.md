# Day 1 Analysis Scripts
This directory contains the Jupyter notebooks used for data analysis and plotting during the semiconductor device characterization workshop.

## Notebooks
- `lab1_plot1.ipynb` — Current–voltage (I–V) characteristics of semiconductor diodes and LEDs.
- `lab1_plot2.ipynb` — Linear fitting analysis of diode and LED data.
- `lab1_plot3.ipynb` — Additional Day 1 plotting and analysis.
