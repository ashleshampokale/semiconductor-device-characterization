# Day 1 — Diode Characterization

This directory contains the Day 1 materials from a semiconductor device characterization workshop at IIT Bombay.

## Experiments
- Current–voltage (I–V) characteristics of semiconductor diodes and LEDs
- Logarithmic diode current analysis
- Cut-in voltage and band-gap relationship

## Directory Contents
- `reports/` — Workshop report and lab reference documents
- `data/` — Excel workbooks containing experimental data and calculations
- `plots/` — Generated plots for the experiments
- `scripts/` — Analysis scripts, if applicable
