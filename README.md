# Semiconductor Device Characterization

Experimental study and electrical characterization of semiconductor devices conducted during a workshop at **IIT Bombay**.

This repository documents laboratory experiments, experimental data, analysis notebooks, and plots developed during the characterization of semiconductor devices. It serves as a record of the experimental work, data analysis, and device behaviour investigated throughout the workshop.

## Experiments Covered

- **Diodes and LEDs:** Current–voltage (I–V) characteristics and analysis of diode and LED behaviour.
- **Solar Cells:** Experimental characterization of solar-cell electrical behaviour.
- **MOS Capacitors:** Capacitance–voltage (C–V) characteristics.
- **MOSFETs:** Device characteristics, body effect, and subthreshold behaviour.

## Tools and Technologies

- **Python** — Numerical analysis and data visualization
- **Jupyter Notebook / Google Colab** — Interactive analysis and plotting
- **NumPy** — Numerical computation and curve fitting
- **Matplotlib** — Experimental data visualization
- **Microsoft Excel** — Experimental data processing and calculations

## Learning Outcomes

- Studied the electrical characteristics of semiconductor devices through laboratory experiments.
- Analysed measured data and visualized device behaviour using plots.
- Applied numerical methods and curve fitting to experimental data where applicable.
- Organized experimental reports, datasets, plots, and analysis notebooks for documentation and reproducibility.

## Acknowledgement

The experimental work documented in this repository was carried out as part of a semiconductor device characterization workshop at **IIT Bombay**.
